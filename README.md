# The Barber Lounge
Single-page booking site for Cesar’s barbershop (services, work clips, call/text).
On disk: Desktop\Clients\CesarBlendss\THE-BARBER-LOUNGE
Get it: download THE-BARBER-LOUNGE.zip, extract, double-click Install-THE-BARBER-LOUNGE.bat.
Start: Desktop shortcut "The Barber Lounge", or Start.bat in that folder.
URL: http://localhost:3847
Needs Node.js LTS once from https://nodejs.org
Do not use git. Explorer double-click only.
Videos (optional): public/videos/facial.mp4, beard-lineup.mp4, mid-fade.mp4.
See GET-ON-PC.txt for the full Windows steps.
