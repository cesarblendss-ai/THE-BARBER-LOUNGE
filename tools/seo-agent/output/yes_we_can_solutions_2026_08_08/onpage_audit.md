# On-Page SEO Audit Checklist for Yes We Can Solutions — Canning Services in Antioch, CA

## CRITICAL (Fix Within 48 Hours)

### 1. **Title Tags**
- **What to Check**: Is the title tag optimized for local intent? 
- **What Good Looks Like**: Title includes "Canning Services", "Antioch, CA", and brand name; around 60 characters long.
- **How to Fix It**: Update the title tag to something like: “Canning Services in Antioch, CA | Yes We Can Solutions”.

### 2. **Meta Descriptions**
- **What to Check**: Is there a unique meta description on each page? 
- **What Good Looks Like**: Description is 150-160 characters, includes keywords and a clear call-to-action.
- **How to Fix It**: Write key descriptions for each page. Example: “Contact Yes We Can Solutions for top-quality canning services in Antioch, CA. Freshness guaranteed!”

### 3. **Header Tags (H1)**
- **What to Check**: Does each page have only one H1 tag that includes primary keywords? 
- **What Good Looks Like**: H1 accurately describes the content and contains the main keyword (e.g., "Professional Canning Services in Antioch, CA").
- **How to Fix It**: Ensure each page has a single, descriptive H1 tag that accurately represents the page content.

### 4. **Mobile Optimization**
- **What to Check**: Is the website mobile-friendly? 
- **What Good Looks Like**: Site loads quickly and elements adjust for mobile viewing.
- **How to Fix It**: Use Google’s Mobile-Friendly Test to identify issues and make necessary adjustments (responsive design, image optimization).

### 5. **404 Errors**
- **What to Check**: Are there any 404 pages that could harm user experience?
- **What Good Looks Like**: All pages should return a valid result.
- **How to Fix It**: Use Google Search Console to identify and fix broken links or redirect them to relevant pages.

## HIGH PRIORITY (Fix This Week)

### 1. **Content Optimization**
- **What to Check**: Does existing content serve local intent and answer key questions?
- **What Good Looks Like**: Content includes local keywords and is informative; ideally 1000+ words per key service page.
- **How to Fix It**: Update content to include FAQs, tips, or guides about canning, with local flavor (e.g., “Best Canning Practices in Antioch”).

### 2. **Image Alt Tags**
- **What to Check**: Are images on the site using proper alt text?
- **What Good Looks Like**: Alt text includes relevant keywords, ensures accessibility, and describes the image.
- **How to Fix It**: Add or modify alt tags for all images on the site to include phrases like “Canning Process in Antioch” or “Vegetable Canning Service”.

## MEDIUM PRIORITY (Fix This Month)

### 1. **Schema Markup**
- **What to Check**: Is relevant schema markup implemented? 
- **What Good Looks Like**: Implementation of LocalBusiness schema, along with Service schema for canning services.
- **How to Fix It**: Use Google’s Structured Data Markup Helper to create and implement the required schema.

### 2. **Internal Linking Structure**
- **What to Check**: Are there internal links that enhance navigation and topical relevance?
- **What Good Looks Like**: Logical internal links connecting related services; at least 3-5 links per page.
- **How to Fix It**: Create links among related services (e.g., from “Pickling Services” to “Canning Tools” page).

### 3. **Content Depth**
- **What to Check**: Is there sufficient depth on core service pages?
- **What Good Looks Like**: At least 2-3 pieces of interconnected content (e.g., blogs, guides) that establish authority.
- **How to Fix It**: Develop content on relevant topics (e.g., benefits of canning, types of canning) and interlink them.

## QUICK WINS (Takes < 30 min each)

### 1. **URL Structure**
- **What to Check**: Are URLs clean and keyword-rich?
- **What Good Looks Like**: URLs are short, descriptive, and use hyphens (e.g., https://yeswecanmobile.com/canning-services-antioch).
- **How to Fix It**: Modify or implement clean URLs for service pages.

### 2. **Page Speed Optimization**
- **What to Check**: How fast does the website load?
- **What Good Looks Like**: Page load time under 3 seconds.
- **How to Fix It**: Compress images and leverage browser caching; tools like Google PageSpeed Insights can provide specific recommendations.

### 3. **Engagement Elements**
- **What to Check**: Are there clear calls-to-action (CTAs) on key pages?
- **What Good Looks Like**: Each page has a visible, compelling CTA (e.g., “Get Your Free Canning Quote Today!”).
- **How to Fix It**: Add and optimize CTAs with contrasting colors and clear language.
